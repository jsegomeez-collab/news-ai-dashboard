# 📂 Carpeta Knowledge — tu "cerebro de marca"

Todo lo que pongas aquí es lo que el motor usa para escribir tus guiones.
Se carga **automáticamente** al arrancar y se vuelve a leer cuando cambian los
archivos (no tienes que pulsar nada). Formatos soportados: `.md`, `.txt`,
`.pdf`, `.docx`.

## Estructura

- `bases-negocio/` → los 4 documentos clave de tu negocio:
  - `problema.md` — el problema que resuelves
  - `cliente-ideal.md` — a quién le hablas
  - `oferta.md` — qué vendes / tu propuesta
  - `competencia.md` — análisis de competencia (se usa con menos peso)
- `tonalidad/` → ejemplos de tu forma de hablar: transcripciones de tus
  videos, mensajes, hilos... cuanto más, mejor imita tu voz.
- `historia/` → tu historia personal y de marca (de dónde vienes, tu "porqué").

No necesitas que existan todos: el motor usa lo que encuentre. Pero cuanta
más calidad pongas aquí, mejores y más "tuyos" serán los guiones.
